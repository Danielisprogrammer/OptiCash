# 💰 OptiCash – Gestion intelligente des dépenses personnelles

**OptiCash** est une application web frontend moderne qui aide les utilisateurs à gérer efficacement leurs dépenses personnelles.  
Elle propose une interface dynamique, responsive et esthétique, ainsi qu’un module de **chat IA** (simulé pour l’instant) pour interagir et recevoir des conseils financiers.

---

## 🚀 Fonctionnalités principales

✅ Gestion des dépenses avec un **formulaire simple** (montant, catégorie, heure).  
✅ **Dashboard interactif** affichant toutes les dépenses sous forme de tableau.  
✅ Calcul automatique du **total des dépenses**.  
✅ **Navigation intuitive** avec liens actifs (Accueil, Ajout, Dashboard, Chat IA).  
✅ **Chat IA intégré** pour interagir avec l’application.  
✅ **Design moderne et responsive** (fonctionne parfaitement sur desktop, tablette et mobile – dès 390px).  
✅ Utilisation de **fonts professionnelles** (Montserrat & Poppins).  

---

## 🛠️ Technologies utilisées

- **HTML5** → structure des pages.  
- **CSS3** → design moderne (variables CSS, hover, responsive design).  
- **JavaScript (ES6)** → logique frontend (formulaire, dashboard, chat IA, liens actifs).  
- **Fonts Google** → Montserrat et Poppins.

## ⚡ Installation & Utilisation

1. **Cloner le projet** ou télécharger les fichiers :  
   
   git clone https://github.com/OptiCash/opticash.git
Ouvrir le projet dans votre éditeur de code (ex : VS Code).

Lancer l’application en ouvrant index.html dans un navigateur moderne (Chrome, Edge, Firefox).

Interagir avec :

Le formulaire pour ajouter des dépenses.

Le dashboard pour visualiser les données.

Le chat IA pour tester l’expérience interactive.
